# Nashi for Windows

The native Windows port is in development. The macOS SwiftUI/AppKit application
cannot be built into a Windows executable directly. This directory will contain
the Windows app, shared operation engine and verification projects.

The intended release is a self-contained Windows x64 app with public, verified
updates. A release is not ready until real Windows build/runtime checks pass.
The public website will distinguish platform availability rather than claiming
unverified feature parity.
